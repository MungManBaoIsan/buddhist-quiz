This card uses Option C — a negative "which of the following is NOT" question. Apply to numbered-list cards where testing all items matters.

The distractor techniques used across the deck:
- Option A (hand-crafted plausible distractors, 80%): wrong answers that are factually adjacent — similar Pali terms, similar numbers. Never duplicate the correct answer.
- Option B (fragment mixing, 10%): recombine real answer fragments into plausible-sounding wrong wholes.
- Option C (negative questions, 10%): rewrite as "Which is NOT one of the X?" with one fabricated item.

For Easy difficulty: cross-chapter random distractors (easy to eliminate). For Medium and Hard: use hand-crafted Option A/B/C distractors.
